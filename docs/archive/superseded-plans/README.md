# Superseded plans

These documents are preserved as design history, not as an active backlog.
Their cache-batching, sketch sorting, candidate-locus regrouping, seed batching,
WAND-lite, broad rescue, SIMD scoring, and manual prefetch directions were all
explored or superseded without producing the required frontier combination of
speed, memory use, and end-to-end output quality.

Do not re-enter one of these paths merely because it sounds plausible in the
original brief. Start with `docs/failed_performance_experiments.md` and require a
new premise plus a falsifiable benchmark before revisiting any of them.

Archived documents:

- `cachebatch_rnaseq_mapper_codex_brief.md`: original cache-batched architecture.
- `constellation_codex_recall_and_search_engine_plan.md`: recall/search-engine plan.
- `newest_project_brief.md`: later mapping-quality and low-level optimization notes.
