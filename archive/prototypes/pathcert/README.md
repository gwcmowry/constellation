# PathCert prototype archive

PathCert was a separate RNA-seq aligner prototype and is not part of the active
Constellation workspace. It is retained here to preserve its implementation and
project brief without making the repository root look like a second live tool.

- `source/`: the complete standalone Rust prototype, including tests and toy data.
- `project-brief.docx`: its original project brief.

No PathCert result is part of the current Constellation performance baseline.
